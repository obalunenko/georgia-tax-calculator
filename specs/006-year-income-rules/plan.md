# Implementation Plan: Year Income Rules for Tax Calculation

**Feature Directory**: `specs/006-year-income-rules` | **Branch**: `fix/spec-gaps-bot-validation`

**Date**: 2026-11-15 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/006-year-income-rules/spec.md`

## Summary

`service.Calculate` gains three rules: it rejects incomes from more than one
calendar year before any conversion, computes the tax once on the total
converted income, and adds a limit warning to the response when the category
is Small Business and the reported year income exceeds 500 000 GEL. The
warning text comes from the service, so the CLI and the bot print the same
line. Both interfaces offer only the first income's year for later incomes.
The 3% category is renamed in the `TaxType` enum ("Small Business (over
limit)") and its `String()` is regenerated with stringer.

## Technical Context

**Language/Version**: Go 1.27.3, single module
`github.com/obalunenko/georgia-tax-calculator` with committed `vendor/`.

**Primary Dependencies**: urfave/cli v3 and Bubble Tea v2 (CLI), telego (bot),
shopspring/decimal (via `pkg/moneyutils`). No dependency changes.

**Storage**: None. The fixed year lives in the CLI form model and the bot
session (in memory), derived from the first captured income.

**Testing**: testify table tests in `internal/taxes/calculator_test.go`,
`internal/service/service_test.go` (and `amount_test.go` style for new
cases), `cmd/ge-tax-calc/tax_menus_test.go`, `cmd/bot/keyboards_test.go`,
`cmd/bot/handlers_test.go`; `go test -race ./...`. Service tests use
`mockConverter` (1:1 conversion), so totals are exact.

**Target Platform**: CLI on linux/darwin/windows; bot on linux/darwin and as a
Docker image.

**Performance Goals**: N/A. The year check runs before conversions, so a
mixed-year request makes no NBG calls.

**Constraints**: Money arithmetic through `pkg/moneyutils` (constitution
III); interfaces call only `internal/service` and use `internal/taxes` for
category lists (constitution I); CLI/bot parity (constitution II);
`taxtype_string.go` regenerated by `make codegen` (constitution VII).

**Scale/Scope**: One service method, one enum value, two interface flows
(`run`, `/calculate`); three categories; any number of incomes.
